# Basteleur

Basteleur and Basteleur Moonlight, by Keussel, Velvetyne Type Foundry. SIL Open Font License 1.1.
Source: https://velvetyne.fr/fonts/basteleur/ and https://gitlab.com/velvetyne/basteleur. Copied from the Pip repo
(`apps/pip-palace/public/fonts/`). Basteleur has one Bold cut and Basteleur Moonlight one Regular cut, so each is
declared at its one real weight. Used by the Pip sub-brand for its wordmark and headings.
